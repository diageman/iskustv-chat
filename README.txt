OKK Review — версия с интерфейсом под Bitrix24

Что изменено:
- основной экран теперь выглядит как рабочее окно проверки чатов
- чат сделан в светлом стиле, ближе к интерфейсу Bitrix24
- системные сообщения в ленте не показываются
- в чате отображаются только сообщения водителя и сотрудника
- строки без новой метки продолжают предыдущее сообщение

Как заполнять чат в админке:
Используйте только такие метки:

Водитель: Добрый день
Сотрудник: Здравствуйте

Если следующая строка идет без новой метки, она продолжит предыдущее сообщение.

Пример:
Водитель: Добрый день
Поставьте только безналичную оплату и все
Профиль по номеру: 79882604647

Сотрудник: Здравствуйте! Вас приветствует таксопарк CASHTAXI.
Изменил вам тип оплаты.

Важно:
- строки с метками вроде "Система:" в чат не выводятся
- неизвестные служебные строки тоже не выводятся, если они не продолжают реплику водителя или сотрудника
- данные сохраняются локально в браузере

Если нужно, следующим шагом можно добавить:
- точнее повторить шапку Bitrix24
- режим скрытой оценки кейса
- фильтр "проверено / не проверено"
- отдельную страницу входа для ОКК
